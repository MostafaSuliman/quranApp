# Professional Islamic App Icon Prompts

## For Nano Banana or Professional AI Image Generators

### Main App Icon (All Sizes)

**Concept**: Modern Islamic Quran Memorization App Icon

**Detailed Prompt**:
```
Create a beautiful, modern Islamic app icon for a Quran memorization application with these specifications:

DESIGN ELEMENTS:
- Central focus: Stylized open Quran/Mushaf with visible Arabic calligraphy
- Background: Rich emerald green gradient (#047857 to #065f46)
- Accent colors: Gold/amber (#f59e0b) for text and decorative elements
- Typography: Elegant Arabic calligraphy visible on the book pages
- Geometric patterns: Subtle Islamic geometric border or corner details
- Crescent: Small, tasteful crescent moon element (optional)

STYLE REQUIREMENTS:
- Modern flat design with subtle depth/shadows
- High contrast for mobile visibility
- Professional, respectful Islamic aesthetic
- Clean lines and readable at small sizes
- No human figures (following Islamic art traditions)
- Suitable for both light and dark backgrounds

TECHNICAL SPECS:
- Square format (1:1 ratio)
- Clean edges suitable for iOS rounded corners
- High resolution for crisp display
- PNG format with transparency support
- Scalable design elements

COLOR PALETTE:
- Primary: Emerald green (#047857)
- Secondary: Deep forest green (#065f46)  
- Accent: Golden amber (#f59e0b)
- Text: White (#ffffff) or cream (#fef7cd)
- Details: Soft gold (#fbbf24)

INSPIRATION:
- Traditional Islamic manuscript illumination
- Modern mosque architecture
- Contemporary Islamic art
- Premium religious app aesthetics
```

### Alternative Minimalist Version

**Prompt for Simple Design**:
```
Design a minimalist Islamic app icon featuring:

CORE ELEMENTS:
- Simple geometric representation of an open book
- Clean Arabic letter "ق" (Qaf for Quran) in elegant calligraphy
- Solid emerald green background (#047857)
- White or gold text/symbols
- Subtle Islamic geometric pattern as background texture

STYLE:
- Ultra-minimal, clean design
- High contrast for excellent visibility
- Timeless, classic aesthetic
- Professional and respectful
- Easily recognizable at any size

PURPOSE: Quran memorization and Islamic education app
TARGET: Muslim users worldwide, all ages
PLATFORMS: iOS, Android, PWA, Web
```

### Icon Variations Needed

1. **App Store Icon (1024x1024)**
   - Highest quality version
   - No transparency
   - Optimized for App Store display

2. **Standard PWA Icons**
   - 192x192px (standard)
   - 512x512px (high-res)
   - 144x144px (Android)

3. **Apple Touch Icons**
   - 180x180px (iPhone)
   - 167x167px (iPad Pro)
   - 152x152px (iPad)
   - 120x120px (iPhone retina)

4. **Favicon Sizes**
   - 32x32px (standard)
   - 16x16px (browser tab)

### Cultural Considerations

**Important Notes for Designer**:
- Avoid human or animal imagery (Islamic art tradition)
- Use geometric patterns and calligraphy
- Ensure Arabic text is authentic and correctly oriented
- Green color represents Islam and nature
- Gold represents knowledge and divine light
- Respect Islamic artistic traditions

### Quality Standards

**Must Have**:
- Vector-based design (scalable)
- Crisp edges at all sizes
- Excellent contrast ratios
- Professional finish
- Culturally appropriate
- Timeless design that won't date quickly

**Nice to Have**:
- Subtle animation potential
- Multiple color variants
- Seasonal variations
- Different cultural adaptations
```

## Usage Instructions

1. **For Nano Banana**: Copy the main prompt and specify exact dimensions needed
2. **For DALL-E/Midjourney**: Use the detailed prompt with "--ar 1:1" for square format
3. **For Professional Designers**: Provide the complete brief with cultural considerations
4. **For Quick Mockups**: Use the minimalist version prompt

## File Naming Convention

When generated, save as:
- `app-icon-1024.png` (App Store)
- `pwa-192x192.png` (PWA standard)
- `pwa-512x512.png` (PWA high-res)
- `apple-touch-icon-180x180.png` (iPhone)
- `favicon-32x32.png` (Browser)

## Testing Checklist

After receiving new icons:
1. ✅ Visibility at 16x16 pixels
2. ✅ Clarity at 1024x1024 pixels  
3. ✅ Cultural appropriateness
4. ✅ Brand consistency
5. ✅ Technical format compliance
6. ✅ Loading performance
7. ✅ Cross-platform compatibility
