QuranApp Settings Test

This test verifies that the settings functionality is working correctly.

Manual Test Instructions

  1. Open the app in your browser: http://localhost:3001/
  2. Navigate to the Settings page
  3. Test each setting:
    • Dark Mode Toggle: Should immediately change the app theme
    • Animation Toggle: Should enable/disable animations
    • Translation Settings: Should show/hide translation text in reading pages
    • Transliteration Settings: Should show/hide transliteration text
    • Reciter Selection: Should change the preferred reciter for audio
    • Playback Speed: Should adjust audio playback speed
    • Reading Mode: Should change default reading mode
    • Notification Time: Should save notification preferences
  4. Navigate to other pages and verify settings are applied
  5. Refresh the browser and verify settings persist

Expected Behavior

  • ✅ Settings changes should take effect immediately
  • ✅ Settings should persist after page refresh
  • ✅ Dark mode should apply to the entire app
  • ✅ Audio settings should affect playback
  • ✅ Translation settings should affect text display
  • ✅ Settings should be synchronized across components

Common Issues (Fixed)

  • ❌ Settings not persisting → FIXED: Added proper localStorage persistence
  • ❌ Dark mode not applying → FIXED: Added DOM initialization and sync
  • ❌ Audio settings disconnect → FIXED: Added preferences-audio store sync
  • ❌ Changes not reflecting → FIXED: Added real-time DOM updates

Developer Console Tests

You can also test settings programmatically in the browser console:

// Test preferences store
const prefsStore = window.usePreferencesStore?.getState?.()
console.log('Current preferences:', prefsStore?.preferences)

// Test dark mode toggle
prefsStore?.toggleDarkMode()

// Test reciter change
prefsStore?.updateReciter('1')

// Test playback speed
prefsStore?.updatePlaybackSpeed(1.5)
